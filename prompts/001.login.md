# 001 · login — filed before it runs (TPR.RULES §4)

Builds ONLY the login. Nothing else rides in this prompt.
Secrets are set in Base44 project secrets, never written
here. Required secret: TELEGRAM_BOT_TOKEN.

## the prompt, verbatim

Build the login for TelePromptR, a Telegram Mini App.
Telegram is the only identity provider. No passwords, no
email, no social logins, no signup form.

FRONT: one page that runs inside Telegram. On load, read
window.Telegram.WebApp.initData and POST it to a backend
function named auth. While checking, show a quiet "checking
signature" state. If the page is opened outside Telegram
(no initData), show one card: "TelePromptR opens from
Telegram" with a button linking to https://t.me/tpr_zenbot.

BACK: a serverless function `auth` that verifies Telegram's
signature server-side:
1. Parse initData as a querystring. Pull out `hash`.
2. data_check_string = remaining fields as k=v, sorted by
   key, joined with newline.
3. secret = HMAC_SHA256(key = "WebAppData",
   message = TELEGRAM_BOT_TOKEN from project secrets).
4. expected = hex HMAC_SHA256(key = secret,
   message = data_check_string).
5. Constant-time compare with `hash`. Reject on mismatch.
6. Reject if auth_date is missing, older than 3600s, or in
   the future. Reject if no user field.
7. Never log the token or raw initData.

ON SUCCESS: upsert a User entity keyed by telegram_id
(unique): username, first_name, last_seen. Start a session.
Return who the person is.

AFTER LOGIN: a dark, card-based screen in the style of a
game battle log (reference: reference/battle-log.png in the
repo). Left column = the session's shape as label: value
rows — your name, telegram id, signed-in time. Right side =
an empty log panel titled "Relay Log" awaiting real events.
Top bar = two running totals, "relayed" and "spent", both 0
for now. No marketing copy anywhere. No fake data anywhere:
empty states say they are empty.

## on exit

Pull the generated code into this branch via the base44
CLI, read the diff, commit. The commit hash is the receipt
(TPR.RULES §6).
