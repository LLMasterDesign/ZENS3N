▛///▞ AUTH · fn:auth, the check that makes login real
server-side verification of Telegram's signature, exact, no
shortcuts.

    1  parse initData as querystring · extract hash
    2  data_check_string = remaining fields k=v · sorted ·
       \n-joined
    3  secret   = HMAC_SHA256("WebAppData", TELEGRAM_BOT_TOKEN)
    4  expected = hex HMAC_SHA256(secret, data_check_string)
    5  constant-time compare vs hash · mismatch → reject
    6  reject if auth_date absent · older than 3600s · future ·
       reject if no user field
    7  success → upsert User by telegram_id · start session ·
       return who

yields :: identity proven by signature, never by claim.
:: ∎
