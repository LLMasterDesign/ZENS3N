# [1N]3OX Atlas

This folder is the inbox for mapping the ZENS3N ecosystem out of Lucius's
head. Read [`.zdx`](.zdx) first: it says exactly what is currently inside.

## Folder rule

- Drop unfinished maps, node notes, folder notes, questions, and fragments
  directly into this folder.
- Add one `.zdx` route for every direct child kept here.
- Use [`MAP.md`](MAP.md) for relationships that are understood.
- Leave uncertain material as its own inbox entry until its role is clear.
- Create a subfolder only after several entries form a stable family.
- `suite-manifest.json` remains the executable 21-node authority.

The Atlas is allowed to be incomplete. It is not allowed to make an unfinished
thought look authoritative.
