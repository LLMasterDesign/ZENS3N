# AEO / AI answer-readiness checklist

AEO here means making the site easy for answer engines and AI systems to interpret accurately. It is not a special ranking switch.

- [x] State what ZENSEN is in one plain sentence near the top: “ZENSEN is runtime infrastructure for persistent AI agents.”
- Give each major idea a descriptive heading and a short direct explanation.
- Prefer visible, stable HTML text over text drawn only inside images or canvas.
- Define unusual terms the first time they appear.
- Keep names, dates, product claims, and links consistent across the site.
- Add an About/Organization source of truth and a contact route.
- Use lists, tables, and labeled cards where they clarify relationships.
- [x] Add `Organization` JSON-LD only when the values are true and maintained. The current block is limited to the visible name, public URL, description, and footer email.
- Keep section IDs stable so future edits can target one semantic unit.
- Do not hide critical claims behind login, animation, or client-only rendering.
