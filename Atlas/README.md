# ZENS3N Atlas

ZENS3N Atlas is the thinking and mapping surface for the ZENS3N ecosystem.
It exists to get the system out of Lucius's head without turning notes into
runtime truth by accident.

## Use it

1. Drop unfinished thoughts into [`INBOX.md`](INBOX.md).
2. Fold understood relationships into [`MAP.md`](MAP.md).
3. Change [`../suite-manifest.json`](../suite-manifest.json) only when the
   executable 21-node graph itself changes.
4. Verify live deployment state before promoting any map statement to fact.

## Boundary

- `Atlas/MAP.md` explains how the ecosystem fits together.
- `Atlas/INBOX.md` holds raw, contradictory, or incomplete thoughts.
- `suite-manifest.json` remains the authoritative suite graph.
- The existing Workdesk Atlas remains the public-site production control plane.
- This branch does not approve DNS, production VPS work, or capacity claims.

## Read order

`INBOX.md → MAP.md → suite-manifest.json → named source or runbook`
